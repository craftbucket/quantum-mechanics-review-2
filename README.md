# 课程复习工作台

`dist/` 是无需安装依赖或启动本地服务的静态学习站。内容包括六门课程的章节知识卡、内置思维导图、主动回忆和自测。原子核物理和传感器从知识地图进入，按关键词提供开卷资料索引。英语区包含词汇卡、中译英和口语计时练习。进度存于访问时所用的浏览器。

## GitHub Pages

管理员在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions** 后，在 **Actions → Deploy course review site** 运行现有工作流。成功运行后，打开部署记录中的地址。

课程原件、教材、原卷、音频和已有英语批注保存在原位置。网页使用文字和数学排版，无需生成 PDF 页图。
